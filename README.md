# psychopy-tools
A collection of utilities and sample scripts for the MEG facility at the Rotman Research Institute, Baycrest

## Dependencies

* `PsychoPy`
* `pypixxlib`

For `PsychoPy`, the standalone package is preferred. 

To get `pypixxlib`, install VPixx Software Tools from 
https://vpixx.com/downloads-and-updates/. 
Then, follow [this](https://docs.vpixx.com/python/introduction-to-vpixx-python-documentation#IntroductiontoVPixxPythondocumentation-InstallingpypixxlibinstandalonePsychoPy(alloperatingsystems)) wiki to 
install `pypixxlib` on top of your `PsychoPy` distro.
